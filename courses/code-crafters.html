Python, Web & Real Projects. This is where coding becomes a real skill with a future attached — and students finish with a portfolio project.

Course details

  • Duration: 12 weeks
  • Class length: 90 minutes
  • Class size: 6–10 students
  • Prerequisites: Comfortable typing; Scratch or Python helpful
  • Tools: Python, Pygame Zero, HTML/CSS, JavaScript, GitHub
  • Price: UGX 420,000 – 720,000
🎯

What they'll learn

  • ✅ Python functions, lists, dictionaries
  • ✅ File handling and error handling
  • ✅ Object-oriented programming (classes)
  • ✅ Pygame Zero game development
  • ✅ HTML structure and CSS design
  • ✅ JavaScript interactivity and the DOM
  • ✅ APIs, data and localStorage
  • ✅ Git/GitHub basics + capstone planning

Projects

What they'll build

💾

Python Apps

Contact book, bank account simulator and a text-based game — real programs with real logic.

🕹️

2D Arcade Game

A complete game with sprites, movement, collision, score and sound using Pygame Zero.

🌐

Interactive Website

A multi-page site with HTML, CSS and JavaScript that responds to clicks, input and user data.

🎓

Capstone Project

Students choose their own build — a game, website, app or tool — and present it to parents and peers at the final showcase. This becomes their first real portfolio piece.

🐙

GitHub Portfolio

Every student leaves with a GitHub profile containing their projects — proof of skill they can share with schools or future employers.

Why this course matters

By age 13, most kids can learn any programming language. This course gives them the foundations in Python and web development to go anywhere next — apps, AI, game development or data science.
